# S2J Package Dashboard - テスト結果

## 概要

本ドキュメントは、S2J Package Dashboard の初期設計における、ユニットテスト等の実行結果の記録を定義します。

## 目的

本ドキュメントは、ユニットテスト等の実行結果を自動生成して記録するための枠である。

## 非目的

本ドキュメントは、テスト戦略や 品質ゲート を定義しない。手書きの仕様本文を持たない。

## 責務

テストランナーが出力する結果を、都度、このファイルに反映する。

## 非責務

何をテストするかは [`testing_spec.md`](../docs/testing_spec.md)、CI での実行は [`cicd.md`](../docs/cicd.md) を正本とします。
