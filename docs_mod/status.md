# S2J Package Dashboard - 実装状況

最終更新: 2026-09-28

## 概要

本ドキュメントは、進行中の実装 initiative の進捗を記録します。

## 目的

フェーズごとの完了数を、一ヵ所で確認できるようにします。

## 非目的

本ドキュメントは、タスク本文や仕様本文を持ちません。完了した initiative の履歴を、ここに残しません。

## 責務

現行 initiative の進捗を維持します。

## 非責務

タスクの一覧と状態は [`implementation.md`](./implementation.md) を正本とします。実装時期は [`use_cases.md`](../docs/use_cases.md) の優先順位を正本とします。仕様準拠の実行結果は [`test-results.md`](./test-results.md) を正本とします。

完了した initiative は `docs/archive/{initiative}/` に退避します。索引は `docs/archive/README.md` とします。
