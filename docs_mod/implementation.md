# S2J Package Dashboard - 実装タスク

## 概要

本ドキュメントは、進行中の実装 initiative のタスクを管理します。

## 目的

フェーズごとの実装タスクと、その状態を保持します。

## 非目的

本ドキュメントは、実装時期や仕様本文を定めません。完了した initiative の記録を、ここに残しません。

## 責務

進行中 initiative のタスク一覧と状態を維持します。

## 非責務

実装時期は [`use_cases.md`](../docs/use_cases.md) の優先順位を正本とします。各関心事の本文は、各専門仕様を正本とします。進捗の集計は [`status.md`](./status.md) を正本とします。

完了した initiative は `docs/archive/{initiative}/` に退避します。索引は `docs/archive/README.md` とします。`docs/` の仕様書は、退避しません。
